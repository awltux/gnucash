      Report designer

      Build a report from the same query, columns and options the native reports use. Preview it, then save it under a name: saved reports live on the server (outside the book) and appear in the Reports list above.

      A flat list prints one row per account; the account tree rolls parents up and adds a subtotal; by period prints one row per year or month in the date range.

      Each checked account means that account and its whole subtree. Nothing checked means every account in the book.
